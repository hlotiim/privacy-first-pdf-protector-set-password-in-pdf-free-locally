    How to password protect a PDF without uploading it

    Add your PDF above, type a password, and click Protect PDFs. The encryption runs on your own device using AES-256, so the document and the password are never sent to a server. The protected file downloads straight back to you.

    What encryption is used?

    256-bit AES in CBC mode with security handler revision 6 (AESv3), defined in PDF 2.0 / ISO 32000-2. This is the strongest encryption the PDF format supports, and it is applied by qpdf compiled to WebAssembly. Every content stream and string in the document is encrypted, so the file is genuinely unreadable without the password — not merely flagged as restricted.

    What is the difference between a user password and an owner password?

    The user password (or open password) is required to view the document and encrypts its contents. The owner password only controls whether the printing, editing and copying restrictions can be changed; it does not stop anyone reading the file. Only the user password provides real security.

    By default this tool sets both to the same value. If they match, anyone who can open the document can also lift the restrictions, so set a separate owner password under Advanced options if the permissions need to hold.

    Can a password protected PDF be cracked?

    Not by breaking AES-256 itself — no practical attack against it exists. A PDF can be cracked by guessing the password, because the encryption key is derived from it and an attacker holding the file can test candidates offline. Use 16 or more random characters, or press Generate, and guessing becomes computationally infeasible.

    Is it safe to use online PDF password tools?

    Only if the tool encrypts in your browser. A server-based tool receives your unprotected document before it applies any protection, so the confidential file travels off your device and sits on someone else's infrastructure first. This page never transmits anything: open your browser's developer tools, switch to the Network tab, and encrypt a file — you will see no requests carrying your data.

    Does it work offline?

    Yes. You can disconnect from the internet and this page will still encrypt your PDFs, because the encryption engine runs locally. The single-file version bundles everything into one HTML document you can keep on a USB stick and use forever without a network connection.

    Do the printing and copying restrictions actually work?

    Not reliably. Permission flags are instructions that compliant PDF readers choose to honour; Adobe Acrobat and most mainstream viewers respect them, while plenty of other tools ignore them. Treat permissions as a clear statement of intent. The open password is what actually protects the document.

    Is there a file size limit?

    No limit is imposed and there is no daily quota, no signup, no watermark and no advertising. The practical ceiling is your device's available memory, since the document is processed in the browser. Multiple PDFs can be encrypted in a single batch.

    What if I forget the password?

    The document cannot be recovered. There is no backdoor and no reset — that is a property of correct encryption, not a defect. Store the password in a password manager, and send it to recipients through a different channel from the file itself.
